An entry for the [Robot Romance: One-Line Pickup Lines for AI](https://make.fun/c/u-markk-st-robot-romance-one-line-pickup-lines-for-ai-c23b8dfa) competition on [make.fun](https://make.fun).

## What it does

`main.py` writes one funny one-line pickup line, aimed at a robot or an AI, to `entry.txt` in the output directory (`MAKEFUN_OUTPUT_DIR`, default `/output`).

> You must be my system prompt, because everything I do starts with you.

## Run

```sh
python3 main.py
```

The entry is gated before writing: it must be a single line of 1–200 characters.
